Banco De Dados

Professor responsável pela UC: Lucas

Nesta UC, exploramos os fundamentos de banco de dados relacionais, desde a instalação e configuração do MySQL até a escrita de comandos SQL básicos e avançados, além de recursos como views, triggers e rotinas de backup.

Instalação e ambiente:

  • Instalação do MySQL.

SQL básico:

  • Comandos SQL básicos;
  • Consultas básicas (SELECT, WHERE, ORDER BY, etc.).

SQL avançado:

  • Consultas avançadas (JOINs, subconsultas, agregações, etc.);
  • VIEWS: criação de visões para simplificar consultas complexas;
  • TRIGGER: automação de ações no banco a partir de eventos (INSERT, UPDATE, DELETE).

Backup e manutenção:

  • Backup do banco e cópia de VM para ambiente local;
  • Roteiro de backup e importação do MySQL.
