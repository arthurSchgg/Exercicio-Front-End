Arquitetura De Sistemas:

Professor responsável pela UC: Lucas

Nesta UC, exploramos padrões de projeto (Design Patterns) e arquitetura em camadas (MVC), aplicando os conceitos na prática por meio de uma Situação de Aprendizagem (SA) com um sistema Java completo em console.

Fundamentos estudados:

  • Design Patterns (Padrões de Projeto);
  • Arquitetura MVC (exemplo prático);
  • POO e tratamento de erros com Try/Catch.

Situação de Aprendizagem (SA) — WegAsset Control:

Sistema de Monitoramento e Gestão de Ativos Industriais desenvolvido em Java puro, via console, simulando uma solução interna da WEG para controle de ativos, sensores, alertas e manutenções em ambiente fabril. Grupos formados de 5 a 6 integrantes.

Arquitetura Utilizada:

  • Entity, Repository (armazenamento em memória com HashMap), Service (regras de negócio), Controller e View, seguindo o padrão MVC;
  • Arquitetura MVC com camadas Service, Repository e Entity, armazenamento em memória (HashMap);
  • View não acessa o Repository diretamente;
  • Enums: PerfilAcesso, StatusAtivo, NivelAlerta, StatusAlerta, StatusManutencao;
  • Exceções customizadas: RegraNegocioException, EntidadeNaoEncontradaException, AcessoNegadoException;
  • Tratamento de erros com try/catch.

Perfis de acesso:

  • Administrador: acesso completo ao sistema;
  • Supervisor: gerencia setores, ativos, sensores, alertas, técnicos, manutenções e relatórios (sem alterar perfis administrativos);
  • Técnico: consulta ativos, sensores e alertas, atualiza manutenções atribuídas a ele;
  • Operador: apenas consulta ativos, setores e alertas abertos.

Ferramentas:

  • Java puro (sem frameworks);
  • Execução via console;
  • POO;
  • HashMap/Map para persistência em memória.
